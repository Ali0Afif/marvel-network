About this project

We're a student group at DTU studying the Wikipedia link structure of 303 Marvel Comics superheroes as part of course 02805. Every week we publish one analysis using that week's network science tools on the frozen dataset.

The network above is real — 303 nodes, 1,784 directed edges from the Week 1 snapshot. Node size scales with in-degree. Spider-Man is the large glowing node. Click any hero to explore their connections.
