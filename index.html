About this project

We're a student group at the Technical University of Denmark studying the Wikipedia link network of 303 Marvel Comics superheroes as part of DTU course 02805. Every week we publish one post using that week's network science tools on the shared dataset — degree distributions, null models, communities, text.

All analysis is in Python + NetworkX. The network above is the real data — 303 nodes, 1,784 directed edges, sized by in-degree. Spider-Man is the large red node.
