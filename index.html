About This Project

We're a student group at DTU exploring the Wikipedia link network of 303 Marvel Comics superheroes. Every week we use that week's tools — network science, NLP, whatever the course throws at us — to find something interesting in the data and write it up here. Built with GitHub Pages and a healthy dose of LLM assistance.

Dataset: github.com/Ali0Afif/marvel-network
